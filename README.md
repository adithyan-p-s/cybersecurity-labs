# Cybersecurity Labs & CTF Walkthroughs

## About Me

I'm an entry-level cybersecurity enthusiast building practical, hands-on skills in Vulnerability Assessment and Penetration Testing (VAPT), ethical hacking, and security operations through authorized labs and CTF (Capture the Flag) machines. This repository documents that learning journey — the methodology, the tools, and the reasoning behind each step.

I am **not** claiming professional penetration-testing or SOC experience. Everything here is self-directed practice on legal, authorized platforms (CTF labs, isolated virtual machines).

## Focus Areas

- Vulnerability Assessment and Penetration Testing (VAPT)
- Ethical Hacking / CTF practice
- Web Application Security
- Linux Fundamentals & Privilege Escalation
- Networking Fundamentals
- SOC / SIEM Fundamentals (Splunk, Wazuh)
